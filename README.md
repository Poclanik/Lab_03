Чем x += 5; отличается от x = x + 5;? Есть ли разница в результате? - Результат один x прибавят 5. Разница в том, что  += сам приводит тип (для byte она важна), а в x = x + 5 может понадобиться явное приведение.

В чём разница между x++ и ++x, если результат сразу используется в выражении
(например, передаётся в Console.WriteLine)-x++ сначала отдаёт старое значение, потом увеличивает x. ++x сначала увеличивает x, потом отдаёт новое значение.
int x = 5;
Console.WriteLine(x++); // 5
x = 5;
Console.WriteLine(++x); // 6

Какой тип данных всегда получается в результате оператора сравнения (==, <, >=
и т.д.)? - bool

Что такое «короткое замыкание» в && и ||? Приведите свой пример, где это имеет
практическое значение. - Для &&: левая часть false, значит всё false. Для ||: левая часть true, значит всё true

Расставьте приоритет для выражения 10 - 2 * 3 + 4 / 2, посчитайте вручную, а
затем проверьте кодом.-Сначала умножение и деление: 2 * 3 = 6, 4 / 2 = 2. Потом сложение и вычитание: 10 - 6 + 2 = 6.
Console.WriteLine(10 - 2 * 3 + 4 / 2); // 6
